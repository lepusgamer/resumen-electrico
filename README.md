# resumen-electrico

- `index.html` — Resumen de Ingeniería Eléctrica.
- `inspector/index.html` — **Asistente Inspector**: control de OT y brigadas contratistas (sector, fechas de planificación, estado, avance), alertas de atrasos y vencimientos, registro de trabajos de emergencia, control de pagos (recepcionada → pagada), calendario mensual, carga por brigada, importación desde Excel y exportación a Google Calendar/Outlook (.ics). Los datos se guardan en el navegador y, opcionalmente, se sincronizan entre dispositivos con una planilla de Google Sheets (Ajustes → Sincronizar).
